# Receitas

As receitas originais (prompts para refazer as fotos de clima) não vieram com o repositório.
As imagens atuais são provisórias, geradas por código. Lembrete: foto gerada pode ilustrar
clima (o método, por exemplo), mas **nunca** pode aparecer como trabalho de cliente.

Para refazer as provisórias: `node arquivos/receitas/gerar-provisorias.cjs arquivos/trabalhos` (precisa do Playwright).
