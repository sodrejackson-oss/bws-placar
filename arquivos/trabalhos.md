# O que é cada foto

> **Provisórias.** O repositório chegou sem a pasta `arquivos/` original. Todas as imagens
> desta pasta foram desenhadas por código (composições simples em tons da paleta) só para a
> demo rodar. Troque pelos arquivos originais ou pelas fotos do estúdio, mantendo os nomes.
